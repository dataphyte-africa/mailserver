## Standard Feature Folder Structure

Each feature directory should evolve to include:

- `README.md`
- `workflow.md`
- `backlog.md`
- `implementation-notes.md`
- optional decision or artifact files as needed

The `README.md` in each feature folder should state:

- objective
- scope
- current state
- target state
- dependencies
- open questions
